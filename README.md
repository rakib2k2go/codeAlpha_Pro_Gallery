# Photos — Pro Gallery (Google Photos style)

- Masonry grid with rounded tiles
- Add images/folders, drag & drop, paste
- Search + sort, and a Recents rail (localStorage)
- Viewer: single right-corner controls (Prev/Next/Close), plus slideshow, fullscreen, download
- Mobile: bottom nav bar with Prev/Next/Close; topbar hides
  Open `index.html` in a modern browser and load images.
